## 설정 방법

설치 후 게임을 실행하고 `OPTIONS > LANGUAGE`에서 **한국어**를 선택함.

## 패치 내용

* 게임 UI·메뉴 문장 번역
* 한글 폰트 적용
* 스토리·인게임·인트로 대사 번역

그림에 들어 있는 영문(로고, 일부 버튼 이미지 등)은 그대로 유지됨. 원본 파일은 게임 폴더의 `kor_bak` 폴더에 백업됨.
