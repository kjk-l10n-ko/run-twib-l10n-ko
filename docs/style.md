# Run 번역 스타일

- 게임: Run — 픽셀 플랫포머. 어둡고 시적인 분위기의 인트로/친구 대사, 짧은 메뉴 라벨.
- 메뉴/UI 라벨: 명사형·간결체 ("시작", "설정", "종료"). 질문형은 "~할까요?" 대신 "~?"로 짧게.
- 서사/대사(Game_intro_text, friend_dialogs_text): 담담하고 시적인 평서문(~다/~했다). 대화체 캐릭터 말투는 원문(en/ja/zh/de 힌트)을 보고 맞춘다.
- 자리표시자(%s, {x}, [tag], \n)는 그대로 유지. 줄바꿈 수 보존.
- 영어 단어로 남겨도 되는 것: FPS, VSYNC. 언어 이름은 한국어 표기("영어","독일어" 등). "Deutsch"처럼 자국어 표기 항목도 한국어 화면에서는 일관성 있게 "독일어".
- 화면 폭이 좁다: 원문보다 현저히 길어지지 않게 한다.
